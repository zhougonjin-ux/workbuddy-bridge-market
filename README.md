# WorkBuddy Bridge — ZCode 插件市场

本仓库是一个 [ZCode](https://z.ai) 插件市场（marketplace），包含插件 **workbuddy-bridge（WorkBuddy 积分桥）**。

在 ZCode 客户端：插件市场 → 添加 → 从 GitHub 仓库添加本仓库，即可安装并随版本发布更新。

插件能力：把腾讯 WorkBuddy / CodeBuddy 的积分与模型接入 ZCode —— 本地 OpenAI/Anthropic 兼容代理、
积分到期优先的多账号调度、本机客户端账号自动导入、微信扫码登录、可视化管理台、每日自动签到。

⚠️ 通过非官方接口调用 WorkBuddy，违反其服务条款，有封号风险，请自行评估。
